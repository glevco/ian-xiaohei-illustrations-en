# Prompt Examples

Copy these prompts directly into Codex. All output text and image lettering should be in English.

## Plan illustrations only

```text
Use $ian-xiaohei-illustrations to plan illustrations without generating images yet.
Analyze where the article below would benefit from illustrations and provide a shot list of about 5 images.
For each image, specify:
- Which paragraph it should follow
- Theme
- Core idea
- Structure type
- What Xiaohei is doing
- Suggested elements
- Suggested English labels

<paste article here>
```

## Article illustrations

```text
Use $ian-xiaohei-illustrations to generate 4 surreal Xiaohei illustrations for the article below.
Requirements: 16:9 landscape, pure white background, black hand-drawn line art, and sparse red/orange/blue handwritten English annotations.
Each image should explain one core structure. Avoid presentation infographics and cute cartoons.

<paste article here>
```

## Illustration strategy for a long article

```text
Use $ian-xiaohei-illustrations to plan illustrations for this long article.
Choose conceptual anchors: key insights, input/output feedback loops, before/after comparisons, common pitfalls, and paths to the next step. Do not space images evenly by default.
Aim for 6–8 images. Provide the shot list first without generating images.

<paste article here>
```

## One image for one idea

```text
Use $ian-xiaohei-illustrations to generate one 16:9 article illustration for this idea:

Trust is built one piece of evidence at a time.

Keep the image surreal but clean. Xiaohei must perform the central action.
Use at most 5 short English labels.
```

## Workflow theme

```text
Use $ian-xiaohei-illustrations to generate one image about turning a single piece of source material into three types of content: traffic, trust, and conversion.
Do not draw a formal flowchart or recreate the one-fish-many-uses example.
Invent a fresh metaphor using simple physical objects, with Xiaohei performing the central action.
```

## Edit: remove a title

```text
Use $ian-xiaohei-illustrations to edit this image.
Remove the "Workflow" title and its underline from the top-left corner. Keep everything else unchanged.
Do not add any text or objects.
```

## Edit: give Xiaohei a stronger role

```text
Use $ian-xiaohei-illustrations to revise this image. The direction is right, but Xiaohei feels decorative.
Keep the core idea and regenerate it with Xiaohei actively making the structure work.
Make the scene a little stranger while retaining a pure white background, clean layout, and minimal English text.
```

## Generate a set of style samples

```text
Use $ian-xiaohei-illustrations to create 5 Xiaohei article illustrations on different themes:
information overload, product validation, compounding content value, a one-person business, and building trust.
Generate each image separately; do not combine them into one image.
```
